전해액 진동분광 도구

ATR-FTIR로 측정한 전해액 스펙트럼을 Kramers–Krönig 절차로 보정해, 투과형 FTIR과 비교 가능한 흡광 스펙트럼과 배위 구조를 얻기 위한 도구 모음입니다.

도구

ATR-FTIR 보정 워크벤치

원시 스펙트럼을 올리면 KK 보정을 수행하고, 보정 전후 피크 위치를 표로 비교하며, 보정된 스펙트럼과 광학상수를 CSV로 내보냅니다. 브라우저에서 바로 실행되며 설치가 필요 없습니다.

열기
CSV · DAT · 붙여넣기 n(ν) · k(ν) 피크 비교 ZnSe · Ge · 다이아몬드

쓰는 순서

  1. 원시 ATR 스펙트럼 파일을 올립니다. 쉼표·탭·공백 구분과 x + 다중 y, (x,y)(x,y)… 배열을 자동 인식합니다.
  2. y축 형식과 흡수 없는 기준선 구간을 지정합니다.
  3. ATR 결정·입사각·n(∞)를 설정하고 보정을 실행합니다.
  4. 피크 표에서 보정 전후 이동량을 확인하고 CSV로 내보냅니다.

보정 방법

1 · 반사율pATR → R → Rs (45°에서 Rp = Rs²)
2 · 위상ln√Rs의 수정 Kramers–Krönig 적분(Maclaurin)으로 Θs
3 · 광학상수Fresnel 식 역산으로 n̂ = n + ik
4 · 흡광도A = 1.74πkνl 로 재구성
검증모사 스펙트럼에서 원시 ATR의 6–7 cm⁻¹ red shift를 0.1 cm⁻¹ 이내로 복원

보정 절차 출처 — Taewoo Kim, Minhaeng Cho, Kyungwon Kwak, Quantitative Analysis of the Li-Ion Solvation Structure in Li-Ion Battery Electrolytes Using ATR-FTIR Spectroscopy, Anal. Chem. 2024, 96, 15924–15930. doi:10.1021/acs.analchem.4c02779
이 도구로 얻은 결과를 발표할 때는 위 논문을 인용하십시오.

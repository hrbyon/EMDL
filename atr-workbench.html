ATR-FTIR · Kramers–Krönig correction

ATR-FTIR 보정 워크벤치

보정 절차

  1. pATR → 반사율 R → Rs (45°: Rp = Rs²)
  2. ln√Rs의 수정 KK 적분(Maclaurin)으로 위상 Θs
  3. Fresnel 역산으로 n̂ = n + ik
  4. A = 1.74πkνl 로 재구성 (식 16)

모사 스펙트럼 검증: 원시 ATR에서 6–7 cm⁻¹ red shift 된 밴드를 0.1 cm⁻¹ 이내로 복원합니다.

읽을 때 주의

  • Rmin이 0.02 아래로 내려간 시료는 전반사 조건이 깨져 그 밴드의 위치·세기를 신뢰할 수 없습니다.
  • n(∞)를 잘못 잡으면 배위수가 과대·과소평가됩니다. 논문에서도 1 M DMC/LiClO₄의 CN이 3.05–3.2로 흔들렸습니다.
  • 부분보정(장비 기본 ATR correction)은 흡광이 강한 전해액에서 거의 효과가 없습니다.

입력 형식

  • 쉼표·탭·공백 구분을 자동 인식합니다.
  • 첫 열이 파수인 다중 열, 또는 (x,y)(x,y)… 쌍 배열 모두 읽습니다.
  • 헤더 행이 있으면 시료 이름으로 씁니다.
  • 파수 간격이 일정하지 않으면 균일 격자로 보간합니다.

쓰는 순서

  1. 원시 ATR 스펙트럼 파일을 올립니다. 쉼표·탭·공백 구분과 x + 다중 y, (x,y)(x,y)… 배열을 자동 인식합니다.
  2. y축 형식과 흡수 없는 기준선 구간을 지정합니다.
  3. ATR 결정·입사각·n(∞)를 설정하고 보정을 실행합니다.
  4. 피크 표에서 보정 전후 이동량을 확인하고 CSV로 내보냅니다.

보정 방법

1 · 반사율pATR → R → Rs (45°에서 Rp = Rs²)
2 · 위상ln√Rs의 수정 Kramers–Krönig 적분(Maclaurin)으로 Θs
3 · 광학상수Fresnel 식 역산으로 n̂ = n + ik
4 · 흡광도A = 1.74πkνl 로 재구성

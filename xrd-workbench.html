Pawley 정제가 알려주는 것

  • 원자 좌표 없이 격자상수, zero shift, 피크 폭(결정 크기), 각 반사의 적분 강도를 정제합니다.
  • 추출한 강도를 시뮬레이션·CIF 강도와 비교하면 구조 모델의 어느 부분이 맞지 않는지 알 수 있습니다.
  • Rwp는 “이 셀로 도달 가능한 최선”이며, 원자 모델의 Rwp와의 차이가 모델 오차입니다.

COF에서 특히 주의할 점

  • 반사가 모두 저각에 있어 a와 zero shift가 강하게 상관됩니다. zero 스캔으로 범위를 확인하고, 가능하면 Si 내부 표준으로 측정하세요.
  • 5° 이하의 넓은 피크는 LP 인자 때문에 저각으로 치우칩니다. LP 가중 프로파일을 켜 두세요.
  • 반사 수가 적으면 삼사정(P1) 셀은 유일하게 정해지지 않습니다. 대칭을 제한한 셀을 쓰세요.

불확도

  • ±σ는 공분산 행렬에서 구하고, 잔차의 직렬 상관(Durbin–Watson)에 따라 √(2/DW)배 키운 값입니다.
  • 배경 제거·smoothing된 데이터는 DW가 작아집니다. 원시 데이터를 쓰면 불확도가 정확해집니다.
  • zero shift 상관에 의한 계통 오차는 ±σ에 포함되지 않습니다.

쓰는 순서

  1. A1에 실험 패턴 파일을 올립니다. (2θ, I)(2θ, I)… 쌍 배열이면 시뮬레이션 열도 자동으로 인식합니다.
  2. B에서 Pawley 실행과 zero 스캔으로 격자상수·결정 크기·반사 강도와 zero shift를 구합니다. 이 zero 값은 A의 모델 fit에 그대로 쓰입니다.
  3. A2에서 구조를 고르고(라이브러리 또는 CIF의 첫 층), 적층 스캔으로 AA·inclined·serrated·AB 중 실험에 맞는 적층을, 치환기가 있으면 무질서 스캔으로 정렬 비율을 찾습니다.
  4. C 종합 결론에서 격자(계산 vs Pawley), 적층(회절 vs GFN-FF 에너지), 층간거리, 강도, 결정 크기를 함께 확인합니다.
  5. 새 구조는 POSCAR로 내보내 xtb POSCAR.vasp --gfnff --opt(또는 DFT)로 최적화한 뒤 CIF로 다시 불러옵니다.

Python으로 쓰기

cof_xrd.py같은 분석을 스크립트로 수행합니다. python cof_xrd.py data.csv --cif model.cif --scan --plot로 Pawley·시뮬레이션 비교·zero 스캔 결과와 CSV·그림을 얻습니다. python cof_xrd.py --selftest로 자체 검증을 실행할 수 있습니다.
읽을 때 주의COF는 반사가 모두 저각에 있어 격자상수와 zero shift가 강하게 상관됩니다. zero 스캔 범위를 함께 보고하고, 가능하면 Si 내부 표준으로 측정하세요.
